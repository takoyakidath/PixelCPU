# ZEN Study プログラミングコンテスト2026夏 提出前チェックリスト

Webページ部門向け。応募締切は**2026年9月13日（日）**です。応募直前に[公式ページ](https://progedu.github.io/webappcontest/2026/summer/index.html)を再確認してください。

## 応募資格・提出先

- [ ] ZEN Study有料会員、ZEN大学生、N高グループ生、N中等部生のいずれかに該当している
- [ ] 自分の所属に合った応募フォームを選んでいる
- [ ] 作品に、教材や既存作品を少し変えただけではない独自性がある
- [ ] 締切までにフォームを送信できるよう、必要事項を事前に揃えている

## コード・権利関係

- [ ] GitHubリポジトリをPublicに設定している
- [ ] 応募フォームへ提出するGitHubリポジトリURLが正しい
- [ ] HTML / CSS / JavaScriptで作られた、動きのあるWebページになっている
- [ ] BootstrapまたはTailwind CSS以外の外部ライブラリを使用していない（許可を得たものがある場合は記録する）
- [ ] 画像、フォント、音声、コードなど、すべての素材について利用・公開条件を確認している
- [ ] 自作でない素材の出典とライセンスをREADMEなどに記載している
- [ ] `LICENSE`があり、リポジトリ自体の利用条件が明確になっている
- [ ] APIキー、トークン、個人情報、ローカル設定ファイルがコミットされていない

## ビルド・公開

- [ ] クリーンな環境で`npm install`が成功する
- [ ] `npm test`がすべて成功する
- [ ] (ビルドステップは廃止。`npm run dev`でindex.htmlをそのまま静的配信できることを確認する)
- [ ] デプロイURLを未ログイン・シークレットウィンドウでも開ける
- [ ] デプロイされた作品が、提出するリポジトリのコードと同じ内容で動く
- [ ] 404、コンソールエラー、読み込みに失敗した画像やファイルがない
- [ ] 審査・結果発表・授業での紹介が終わるまで、リポジトリと作品URLを公開状態に保てる

## 動作・使いやすさ

- [ ] PC版Google Chromeで主要操作を一通り確認した
- [ ] スマートフォン版Google Chromeで主要操作を一通り確認した
- [ ] 狭い画面でも文字、ボタン、コード、回路図が重ならず操作できる
- [ ] 初回オンボーディングだけで基本操作を始められる
- [ ] キーボード操作時にフォーカス位置が分かり、主要ボタンを操作できる
- [ ] 文字と背景、状態表示の色に十分なコントラストがある
- [ ] 高速実行、停止、リセット、エラー入力を試しても操作不能にならない
- [ ] 6本のサンプルがすべてアセンブル・実行でき、説明どおりの結果になる

- [ ] READMEに作品概要、特徴、使い方、ローカル起動方法が記載されている
