# 統計パネル文言

## パネル全体

**見出し:** CPUの仕事量

**説明:** この実行でCPUが行った処理を、クロック、命令、データ転送などの回数で振り返れます。

## 集計項目

| フィールド名 | 表示見出し | 説明文 |
|---|---|---|
| `totalClocks` | 総クロック数 | CPUが処理を一段階ずつ進めた回数です。 |
| `totalInstructions` | 実行した命令数 | 完了したアセンブリ命令の合計です。 |
| `busTransferCount` | バス転送回数 | CPU内で値がバスを通って移動した回数です。 |
| `busTransferBits` | 転送した総ビット数 | バスを通って運ばれたデータ量の合計です。 |
| `aluOpCount` | ALU演算回数 | ALUが計算や比較を行った回数です。 |
| `stackOpCount` | スタック操作回数 | スタックへ値を積んだ回数と、取り出した回数の合計です。 |
| `perInstructionBreakdown` | 命令ごとの実行回数 | それぞれの命令が何回実行されたかを示します（例: `{mnemonic}` × {count}回）。 |
