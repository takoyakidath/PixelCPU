# 初回起動時オンボーディング文言

## 1. コードエディタ

**見出し:** CPUに命令を書いてみよう

ここにアセンブリを書きます。最初は用意されたサンプルを選ぶだけでも、CPUの動きを試せます。

## 2. Debuggerボタン

**見出し:** 1クロックずつ進めよう

まずは「1クロック」を押してみましょう。命令が小さな処理に分かれて、少しずつ実行されます。

## 3. 回路図

**見出し:** 値が移動する道を見よう

光っている線は、いま値が通っている場所です。どこからどこへ運ばれるかを追ってみましょう。

## 4. レジスタビューア

**見出し:** CPUの小さな記憶場所

レジスタは、計算中の値を一時的に覚える場所です。書き換わった値に注目してみましょう。

## 5. RAMビューア

**見出し:** プログラムとデータの置き場所

RAMには命令とデータが入っています。実行中に読み書きされた場所が変化する様子を確認できます。

## 完了メッセージ

準備は完了です。「実行」なら連続で、「1命令」なら命令ごとに観察できます。いつでも自分のペースでCPUの中を探検してみてください。
